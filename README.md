## Демо

[Vercel](https://hero-scroll-flax.vercel.app/)

## Стек

- **Next.js 16.3.3** (App Router)
- **TypeScript 5**
- **GSAP 3.15** + **@gsap/react**
- **Lenis 1.3**
- **CSS Modules**

## Запуск локально

Требуется Node.js 24+ и npm.

```bash
npm install
npm run dev
```

## Заметки по реализации

### Решения

```text
- Отступы в сетки изображений сделаны через CSS-переменные, что бы можно было менять их в одном месте. Это так же решает баг из референса.
- Стартовая позиция сетки изображений задается через fromTo а не инлайн (как в референсе) - по принципу одного источника правды.
- Изображения подключены через Image для оптимизированной загрузки в Next.js.
- Шрифты не подключал сознательно - тянутся с девайса.
- Lenis css не подключен сознательно, что бы не тянуть лишний css, а подключать только js.
- Статические импорты изображений вместо строковых - для оптимизации кэша и обращений к серверу.
- Все остальные решения - стандартны.
```

### Компромиссы ради референса

```text
- Lenis для соответствия референсу.
- margin-top: 275vh трюк - делал бы иначе, но задача была максимально приблизиться к референсу.
- Анимация сетки изображений - тоже заморочка по коду только для приближения к референсу, можно было проще.
```

### Что можно улучшить

```text
- Сделать связку таймлайна и задержек анимации через переменную - для управление в одном месте, без необходимости ручной правки кажого этапа.
- Уйти от трюка с margin-top: 275vh или связать с переменной, что бы было проще менять и иметь контроль над этим в одном месте.
- Откложить загрузку GSAP для оптимизации загрузки бандла.
```

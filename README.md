## Стек

- **Next.js 16.3.3** (App Router)
- **TypeScript 5**
- **GSAP 3.15** + **@gsap/react**
- **Lenis 1.3**
- **CSS Modules**

## Запуск локально

Требуется Node.js 24+ и npm.

```bash
npm install
npm run dev
```

## Заметки по реализации

### Решения

```text
- улучшенные оступы, что бы было динамичнее и исбавиться от багов в рефере
- COLUMN_OFFSETS fromTo а не инлайн - по принципу одного источника
- Image from "next/image" is used for optimized image loading in Next.js.
- шрифты не подключал сознательно - тянутся с девайса
- Lenis css не подключен сознательно
- статические импорты вместо строковых - для оптимизации кэша и запросов к серверу
```

### Компромиссы ради референса

```text
Lenis и margin-top: 275svh - делал бы иначе, но задача была максимально приблизиться к референсу. GALLERY_COLUMNS с квадратами - тоже заморочка по коду только для соответствия референсу.
```

### Что можно улучшить

```text
- сделать связку флоу анимации через переменную - для замены в одном месте
- уйти от margin-top: 275svh или связать с переменной, что бы было проще менять
- откладывать загрузку GSAP для оптимизации по лайтхаусу
```
